# Report Structure and Templates

This document provides complete page-by-page templates and formatting requirements for the earnings update DOCX report.

## Complete Report Structure

**REPORT STRUCTURE:**

---

## PAGE 1: EARNINGS SUMMARY

**Top Section - Header:**
```
[COMPANY NAME] ([TICKER])
[QUARTER] [YEAR] EARNINGS UPDATE

[Current Date]

Rating: [MAINTAIN/RAISE/LOWER] [RATING]
Price (as of [date]): $XX.XX
Price Target: [OLD → NEW if changed, or MAINTAIN $XXX]
```

(The skill assumes prior coverage exists — see SKILL.md Section 7. If the user has no prior estimates, stop and refer them to an initiation report instead.)

**Top Section - Quick Summary Box:**
```

─────────────────────────────────────────────────

```

X% estimate), while [segment] grew X% (vs. X% estimate). Management highlighted

view.

[Detailed margin analysis paragraph...]

■ **Guidance raised / maintained / lowered - implies [interpretation]**

[Detailed guidance analysis paragraph...]

[Investment conclusion paragraph...]

## FORMATTING REQUIREMENTS

### 1. Page 1 Requirements
- Clear rating (MAINTAIN OUTPERFORM, RAISE TO BUY, etc.)
- Updated price target prominently displayed
- Summary table with old/new estimates
- 3-4 paragraph-length bullets with ■ character

### 2. All Tables Requirements
- Source line at bottom
- Clear column headers
- Shading for header rows

### 3. All Charts Requirements
- "Figure X - [Title]" caption above
- "Source: [Source]" line below
- Professional styling

### 4. Year Notation
- Use A for actual (Q3'24A)
- Use E for estimate (Q4'24E)

### 5. Writing Style
- Lead with numbers ("Revenue grew 15% to $1.2B" not "Strong revenue growth")
- Use "vs." not "versus"
- Be direct and concise
- Focus on what's NEW

### 6. Source Attribution Requirements ⭐⭐⭐

Citation format depends on tier (see SKILL.md Section 5 for the full tier table). Pick the right format for each data point — do not mix.

**Tier 1 (MCP only):** `Source: DefeatBeta MCP <tool>, <ticker>, fiscal period <YYYY-MM-DD>, retrieved <date>`. For transcript-derived quotes, also cite speaker + paragraph where available. No URLs.

**Tier 2 (MCP preferred, web fallback):** MCP rows use the T1 format; fallback rows are prefixed `Fallback source:` and include URL + retrieval date + the reason MCP did not cover the row. Keep MCP and fallback visually separate.

**Tier 3 (web only):** `Source: <publication / data provider>, as of <date>` (consensus needs pre-earnings date) or `Source: <publication>, <URL>, retrieved <date>` (news / IR pages). No pretense of MCP coverage.

## Citation Examples for Specific Content

### Tier 1 example — Beat/Miss (combines T1 reported + T3 consensus):
```
Revenue of $2.45B beat consensus of $2.39B by $60M (2.5%)¹

¹ Reported revenue: DefeatBeta MCP get_stock_quarterly_income_statement, XYZ,
  fiscal period 2026-03-31, retrieved May 13, 2026.
  Consensus: Yahoo Finance, as of market close April 29, 2026 (pre-earnings).
```

### Tier 1 example — Guidance (MCP transcript, both current and prior):
```
Management raised FY2024 revenue guidance to $9.8-10.0B from prior $9.5-9.7B²

² Current guidance: DefeatBeta MCP get_stock_earning_call_transcript, XYZ FY2026 Q2,
  report date April 30, 2026, CFO prepared remarks, paragraph 14.
  Prior guidance: DefeatBeta MCP get_stock_earning_call_transcript, XYZ FY2026 Q1,
  CFO remarks, paragraph 9.
```

### Tier 2 example — Segment revenue with web fallback:
```
Cloud segment revenue grew 28% YoY to $1.85B³

³ DefeatBeta MCP get_quarterly_revenue_by_segment, XYZ, fiscal period 2026-03-31,
  retrieved May 13, 2026.
```
If MCP didn't return the segment for this period:
```
Cloud segment revenue grew 28% YoY to $1.85B³

³ Fallback source: XYZ Q2 FY2026 earnings press release,
  https://investor.xyz.com/q2-fy26-results, retrieved May 13, 2026.
  (DefeatBeta MCP get_quarterly_revenue_by_segment did not cover this period.)
```

### Tier 3 example — Operating metric (MCP does not cover):
```
Enterprise customers grew 23% YoY to 845, with net revenue retention at 128%⁴

⁴ XYZ Q2 FY2026 investor presentation, slide 12 (customer count and NRR);
  Company IR site, https://investor.xyz.com/q2-fy26, retrieved May 13, 2026.
```

### Tier 3 example — Analyst price targets:
```
Average sell-side price target is $145.74 (43 analysts), implying ~48% upside⁵

⁵ TipRanks analyst consensus, retrieved May 13, 2026 (3-month window).
```
